# Explicit boundary and surface patching

Approved implementation sequence: 0.17.3 diagnostics, 0.17.4 exact authoring,
0.17.5 composition and real-scene acceptance. The 0.18–0.20 sequence is unchanged.
Requirement reference: [R01–R10](../requirements/explicit-boundary-surface-patching.md).

## 0.17.3

- Stateless `mesh.boundary.inspect` on exact EDGE SelectionSets; `mesh_selection: 2`.
- Components and selected/surrounding degrees are separate. Hidden rails,
  overlap, missing paths, corners, ambiguity, and incomplete search are explicit.
- A path is unique only after edge-removal reachability checks rule out alternatives.
  Searches stop at a visit/deadline budget; no exhaustive simple-path enumeration.
- Grid Fill accepts uniquely resolved two-chain boundaries. A single loop requires
  explicit corners (0.17.4); two closed loops and mixed inputs are rejected.
- Native automatic rail search is restricted to the validated edges on the detached
  working BMesh. All temporary hide flags are restored before writeback.
- Failures retain their existing outer code and structured reason, phase, evidence,
  writeback/recovery and generation fields through MCP.
- Protocol 1 and transaction capability 13 remain unchanged.

## 0.17.4

- Exact single-vertex references and directed EDGE paths, four-path/loop-corner
  Grid Fill, create_edge, create_face and open bridge use the common transaction writer.
- Grid generation uses an isolated BMesh containing only the confirmed boundary;
  native element references and graph distances establish the lattice correspondence.
- Candidate triangulation, surrounding-geometry contact checks, fixed-boundary
  harmonic UV/weights, material/color source checks and output budgets precede guards.
- Creation evidence is separate from exact SURVIVED/CREATED lineage and available
  through paginated ComponentMap inspection (`direction=CREATION_EVIDENCE`).
- Capability versions: `mesh_topology: 6`, `mesh_component_map: 5`.
- Synthetic and live evidence is recorded in the linked validation document.

## 0.17.5

Local quality scopes, cumulative maximum displacement, nested batch aliases and
boundary capture annotations are implemented. The synthetic split-patch workflow,
native save/UI collaboration and real checkpoint-copy rollback/save/reload gates
have passed. Capability versions are validation 3, deformation 2, batch 6 and capture 4.
The real case preserves all 3367 original vertices and weights, 56382 old UV/Pin
corners, 761 Group definitions/locks and 1692 other objects. The central 60-edge seam
is closed; four uncovered interior points remain an explicitly labelled initial form.
Engineering R01–R10 is complete; artistic approval is pending. Evidence and limitations:
[acceptance record](../validation/2026-09-03-explicit-boundary-patching.md).
