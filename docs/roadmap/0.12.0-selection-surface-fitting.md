# Blender Research MCP 0.12.0 — SelectionSet and evaluated surface fitting

- Status: implemented and validated in Blender 4.2.23
- Target package and bundled add-on version: `0.12.0`
- Protocol: `1`
- Transaction capability: `6`
- Existing Mesh topology capability: `1`

## Purpose

0.12 turns exact component indices into reusable revision-bound semantic resources and
adds read-only evaluated-surface evidence plus topology-preserving deformation. The
first vertical slice fits writable eye-white/cornea proxy geometry to a character's
evaluated eyelid without exposing arbitrary Python, BMesh, RNA, raw whole-Mesh arrays,
or task-specific `fix_eye` commands.

The general long-term requirements are recorded in
[`../requirements/general-mesh-authoring.md`](../requirements/general-mesh-authoring.md).
This release implements its first stage only. ComponentMap/topology revision follows
in 0.13, UV and weights in 0.14, and Shape-Key writes/evaluated materialization in
0.15.

## Revision and SelectionSet contract

`mesh.inspect` adds a content-bound `mesh_revision_id`. New read-only tools query,
derive, page, and release immutable SelectionSets. Each resource records exact object
and Mesh evidence, domain, sorted indices, optional weights, source query, and SHA-256.
SelectionSet operations never alter Blender's current selection.

Queries cover explicit/all components, local/world sphere, box and plane volumes,
material slots, normal cones, face area, edge length, boundaries, non-manifold
components, connected regions, and capture-bound point/box/lasso evidence. Derivation
covers set operations, expansion/contraction, boundaries, connected regions, domain
conversion, and bounded geodesic falloff.

The resource book keeps at most 64 selections and 2,000,000 stored component indices.
LRU eviction is explicit through stable expired-resource errors. Every use rechecks
identity, complete users, and the full Mesh fingerprint.

## Evaluated surfaces and validation

`mesh.surface.prepare` creates a BASE or EVALUATED world-space SurfaceRef. Evaluated
targets may contain Shape Keys, Armatures, and Modifiers because the target remains
read-only. Evidence includes scene, view layer, frame, object transform, base revision,
evaluated vertices/triangles, and a complete evaluated fingerprint.

At most eight SurfaceRefs and two million evaluated triangles are retained. Closest
point and ray queries return bounded samples plus min/max/mean/RMS/percentile evidence
and threshold SelectionSets. Signed distances are authoritative only for closed,
manifold, consistently oriented targets.

`mesh.validate` covers non-manifold and degenerate components, orientation,
self-intersection, target-surface intersection, distance, and penetration. Reports are
read-only, bounded, and return SelectionSets that can be inspected or highlighted by a
later workflow.

## Topology-preserving semantic deformation

`mesh.edit` retains every 0.11 operation and adds SelectionSet-targeted `set_positions`,
`smooth`, `relax`, `project`, `shrinkwrap`, `inflate`, and `flatten` operations. These
operations preserve topology and protected attributes. Large semantic regions execute
inside Blender; only explicit position arrays remain limited to 4,096 vertices.

Changed calls update one Mesh revision, record one Mesh delta, advance scene generation
once, and return a SelectionSet rebound to the after-revision. OBJECT scope performs
reversible single-user copying when required; SHARED_DATA retains complete user-set
authority. Meshes with Shape Keys remain write-blocked in 0.12.

## Transaction, compatibility, and authority

Transaction capability 6 adds revision-resource lifecycle without weakening current
identity, user, fingerprint, mode, Scene, View Layer, frame, or Camera conflicts.
Rollback restores data while preserving user UI. Native Blender save still adopts the
visible transaction before serialization and prevents later Agent rollback.

New capabilities are `mesh_selection: 1`, `mesh_surface_query: 1`,
`mesh_deformation: 1`, and `mesh_validation: 1`. A 0.12 server retains every compatible
0.11 tool against an older add-on; new tools fail independently with
`CAPABILITY_MISMATCH`.

## Acceptance

Automated tests cover strict schemas, resource budgets and eviction, local/world/screen
queries, evaluated-target drift, distance/sign evidence, all seven deformations,
OBJECT/SHARED_DATA scope, transaction terminal paths, compatibility, Python 3.11
syntax, packaging, and skill resources.

The Blender 4.2.23 gate uses both a deterministic fixture and a temporary copy of
`test-model.blend`. The real scene treats `绯雪_edit_mesh` as a read-only evaluated
target, discovers a writable eye proxy through generic inspection/query tools, fits it,
validates distance and penetration, proves rollback/commit/disconnect/native-save
behavior, records multi-view evidence, and preserves the source file SHA-256.
