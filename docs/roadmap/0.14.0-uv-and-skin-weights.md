# Blender Research MCP 0.14.0 — UV and skin weights

- Status: implementation in progress
- Target package and bundled add-on version: `0.14.0`
- Protocol: `1`
- Transaction capability: `9`

## Purpose

0.14 adds exact UV-layer and object/Mesh deformation-weight authority to the existing
revision-aware topology system. It lets a modeling workflow preserve or intentionally
replace the data that makes a Mesh render and deform correctly instead of treating
those dependencies as opaque blockers.

## Public surface

- `mesh.uv.inspect/edit` pages UV layers, corners, islands, and seams and performs typed
  layer, coordinate, pin, seam, transform, unwrap, and pack operations.
- `mesh.weights.inspect/edit` pages group schemas and sparse weights and performs typed
  group lifecycle, set, clear, normalize, and influence-limit operations.
- `mesh.attribute.transfer` copies UVs or weights through exact topology,
  nearest-vertex, or barycentric nearest-surface mappings.
- `mesh.validate` adds UV bounds, degeneracy, overlap, stretch, weight sum, influence,
  assignment, and deform-group checks.
- `mesh.batch.execute` adds the same typed attribute steps while retaining static
  preflight, named evidence, one-generation success, and whole-transaction recovery.

## Ownership and migration

UVs, pins, seams, and UV-layer roles are Mesh data. Vertex-group schema is object data
while sparse weights are stored against Mesh vertices. Shared-data writes therefore
require explicit scope and, for weights, identical exact group schemas across all
users.

Topology and separation default to preserving/interpolating both domains. Callers can
instead reject present data or discard result data. Every preservation path validates
the complete resulting schema and values before accepting the write.

## Compatibility and limits

The protocol, request/response limits, geometry budgets, and Blender 4.2.23/Python 3.11
targets remain unchanged. Shape-Key Meshes accept topology-stable UV/weight edits but
not topology changes. Custom normals, generic attributes, Shape-Key writes, evaluated
Mesh materialization, Modifier Apply, and general retopology remain later work.

The Blender gate uses deterministic UV/Armature/shared-data fixtures and a temporary
copy of `test-model.blend`. It must prove official unwrap/pack isolation, evaluated
deformation, topology/separation migration, batch rollback, native-save adoption, and
unchanged source files.
